# Library REST API

A RESTful API built with Node.js and Express.js, using Mongoose to interact with MongoDB.

---

## 🚀 Tech Stack

- **Runtime:** Node.js
- **Framework:** Express.js
- **Database:** MongoDB (via Mongoose ODM)
- **Testing Tool:** Thunder Client

---
